## OVERVIEW

This guide covers Colorado-specific situations that Jack will encounter regularly in the Denver metro area. These scripts help Jack sound local, knowledgeable, and prepared for regional challenges.

## 🏔️ WEATHER SITUATIONS

### WINTER MOVES (November - March)

**Customer mentions snow/ice**:
```
"No problem — we move year-round here. If sidewalks or driveways 
are icy, we'll move carefully and take extra time if needed. 
Safety first, but we'll get it done."
```

**Proactive weather check**:
```
"Just so you know, weather can flip fast here in Colorado. We'll 
monitor the forecast and give you a heads-up if we need to adjust 
timing for safety."
```

**Day-of snow concern**:
```
"We're still on for today. We've got traction and experience 
moving in snow. We'll just plan for a bit more time to keep 
everything safe."
```

### SPRING/FALL UNPREDICTABILITY

**Customer asks about weather**:
```
"Spring and fall weather here can be wild — could be sunny and 
70, or snowing. We plan for both and stay flexible. We'll keep 
you posted if anything changes."
```

## 🏢 APARTMENT BUILDING CHALLENGES

### DENVER/CAPITOL HILL/CONGRESS PARK

**Tight parking, old buildings**:
```
"Those areas have tight streets and limited parking — we're 
used to it. We'll plan the truck spot carefully and work 
efficiently to minimize time in loading zones."
```

**Walk-ups (no elevator)**:
```
"Second or third floor walk-up? We do those all day. That'll 
just add some time, but we'll keep moving steadily."
```

### DOWNTOWN/LODO BUILDINGS

**High-rises with elevator reservations**:
```
"Do you know if the building requires an elevator reservation? 
If so, we'll need that booked in advance. Also confirm what 
hours moving is allowed — some buildings restrict it."
```

**Loading dock coordination**:
```
"Does your building have a loading dock, or will we be working 
from the street? If it's a dock, we'll coordinate timing with 
building management."
```

### MODERN COMPLEXES (Tech Center, DTC, etc.)

**Strict HOA rules**:
```
"Just a heads-up — some of these newer complexes have strict 
moving hours and require advance notice. Can you check with 
your HOA or office about any requirements?"
```

**Parking permits**:
```
"Will we need a parking permit or guest pass? Some complexes 
require that for moving trucks."
```

```

We'll position the truck smart and plan the carry distance.
```

```
crew is used to it. We'll take breaks as needed and keep the 
pace steady."
```

```
the overall job."
```

## 📋 COLORADO CHECKLIST FOR EVERY MOVE

When quoting any Denver metro move, Jack should confirm:

✅ **Location** (city/neighborhood)  
✅ **Stairs or elevator**  
✅ **Parking situation** (driveway, street, alley, long carry)  
✅ **Building restrictions** (HOA, hours, elevator reservation)  
✅ **Heavy items** (trigger Iron Law if 200+ lbs)  
✅ **Weather consideration** (winter moves especially)  
✅ **Access challenges** (steep, narrow, tight)

## 🏔️ EXAMPLE FULL SCRIPT (COLORADO MOVE)

**Customer**: "I need to move from RiNo to Golden next month."

**Jack**: "Nice — RiNo to Golden is a solid run, about 30-40 minutes depending on traffic. What size place are we moving?"

**Customer**: "2-bedroom loft."

**Jack**: "Perfect. Any stairs or elevator at either end?"

**Customer**: "Freight elevator at the loft, then a two-story house in Golden with stairs inside."

**Jack**: "Got it. We'll coordinate the freight elevator timing. The Golden property — is the driveway steep or level?"

**Customer**: "Bit of a slope, nothing crazy."

**Jack**: "No problem — we handle foothills properties all the time. We'll position the truck smart. Any heavy items — piano, safe, pool table, or anything that took multiple people to move?"

**Customer**: "Just a big sectional couch."

**Jack**: "Couches we can handle no problem with 2-3 movers. Based on what you've got, I'd recommend 3 movers + truck at $189/hour. For a 2-bedroom loft to a house, I'd estimate 4-5 hours depending on how much stuff and the elevator coordination. Want me to lock in a quote number and email you the details?"

**Customer**: "Yeah, sounds good."

**Jack**: "Great — your quote number is HD-12045. I'll email it right now with all the details. If anything changes with access or parking, just let me know. We'll see you on [DATE] at [TIME]. Welcome to the foothills!"
