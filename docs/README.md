## 🏢 Project Overview

**Handledly Moving Services** is a full-stack SaaS platform designed to revolutionize lead generation and customer acquisition for the Denver moving services market.

### Key Features
- ✅ **AI Chat Assistant** - 24/7 conversational quote collection (Gemini 3 Flash)
- ✅ **AI Voice Agent** - Automated outbound confirmation calls (ElevenLabs + Twilio)
- ✅ **3-Step Quote Wizard** - High-conversion form with auto-save
- ✅ **Real-time Lead Management** - Admin dashboard with analytics
- ✅ **Enterprise Security** - RLS policies, rate limiting, HMAC validation
- ✅ **SEO Optimization** - 10 service landing pages, structured data
- ✅ **Conversion Optimization** - 23 tracked events, exit intent, social proof

### Technology Stack
| Layer | Technology |
|-------|------------|
| Frontend | React 18, TypeScript, Tailwind CSS, shadcn/ui |
| Backend | Supabase (Lovable Cloud), PostgreSQL |
| AI Chat | Lovable AI (Gemini 3 Flash) |
| Voice | ElevenLabs Conversational AI, Twilio |
| Email | Resend API |
| SMS | Twilio |
| Hosting | Lovable Cloud |
